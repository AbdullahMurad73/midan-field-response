# مشروع ميدان — نظام الاستجابة الميدانية والربط اللحظي

نظام ويب لحظي (Real-Time) لإدارة ومتابعة مراقبي اللجان المدرسية أثناء الاختبارات.
يتيح لغرفة التحكم متابعة حالة كل لجنة لحظياً، واستقبال البلاغات الميدانية والاستجابة لها فوراً.

## المشكلة التي يحلها

أثناء فترات الاختبارات، يعتمد التواصل بين غرفة التحكم والمراقبين الميدانيين على الاتصال الهاتفي
والورق — ما يعني بطء الاستجابة، وضياع البلاغات، وغياب سجل موثّق لما حدث.
"ميدان" ينقل هذا التواصل إلى قناة لحظية واحدة موثّقة.

## المزايا

- **ربط لحظي** عبر WebSocket — تحديث الحالة دون إعادة تحميل الصفحة.
- **لوحة تحكم مركزية** لمتابعة جميع اللجان في وقت واحد.
- **لوحة المراقب الميداني** لرفع البلاغات ومتابعة التعليمات.
- **مصادقة آمنة** عبر JWT مع تشفير كلمات المرور (bcrypt).
- **سجل كامل** لكل بلاغ واستجابة.

## البنية التقنية

| الطبقة | التقنيات |
|---|---|
| الواجهة الأمامية | React 19، Vite، React Router، Tailwind CSS، Lucide Icons |
| الواجهة الخلفية | Node.js، Express 5 |
| قاعدة البيانات | PostgreSQL (عبر `pg`) |
| الربط اللحظي | Socket.io |
| المصادقة | JWT + bcryptjs |

## هيكل المشروع

```
meydan-backend/     # خادم Express + Socket.io + PostgreSQL
meydan-frontend/    # واجهة React (Vite)
```

## التشغيل محلياً

### 1. المتطلبات
- Node.js 18+
- PostgreSQL 14+

### 2. الواجهة الخلفية

```bash
cd meydan-backend
npm install
cp .env.example .env    # ثم عدّل القيم
npm run dev
```

### 3. الواجهة الأمامية

```bash
cd meydan-frontend
npm install
npm run dev
```

## متغيرات البيئة

انسخ `.env.example` إلى `.env` واملأ القيم:

| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط الاتصال بقاعدة PostgreSQL |
| `JWT_SECRET` | مفتاح توقيع الرموز — اجعله عشوائياً وطويلاً |
| `PORT` | منفذ الخادم (افتراضي 5000) |

> ⚠️ ملف `.env` مستثنى من Git عمداً. لا ترفعه أبداً.
